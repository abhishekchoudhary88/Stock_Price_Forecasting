📈 AI Stock Market Forecasting using LSTM
🚀 Project Overview

This project is an AI-powered Stock Market Forecasting System built using Deep Learning techniques.
The system analyzes historical stock market data and predicts future stock closing prices using an LSTM (Long Short-Term Memory) neural network.

The project also includes:

Data preprocessing
Feature engineering
Exploratory Data Analysis (EDA)
Trend visualization
Interactive Streamlit dashboard
🎯 Objective

The main objective of this project is to:

Analyze historical stock market trends
Predict future stock prices
Understand time-series forecasting using Deep Learning
Build a professional AI dashboard

Why LSTM?

LSTM is effective for time-series forecasting
It can remember past patterns and trends
Suitable for sequential financial data
